# Как выложить игру на Яндекс Игры

Шпаргалка, что настроить в консоли разработчика, чтобы заработали топы,
покупки, реклама и сохранения.

## 1. Собрать архив

```
node tools/test.js
node tools/build.js
```

Первая команда проверяет игру, вторая собирает `dist/fisherman-bay.zip`
(около 150 КБ). Этот zip и загружаем в консоль.

## 2. Черновик игры

Консоль: https://games.yandex.ru/console — «Добавить приложение».

- Название: **Рыбацкая бухта** / **Fisherman Bay**
- Языки: русский и английский
- Категории: казуальные, симуляторы (или «спорт» — рыбалка)
- Возраст: 0+
- Ориентация: любая (игра подстраивается и под телефон, и под компьютер)
- Облачные сохранения: включить

## 3. Таблицы лидеров

В разделе «Лидерборды» создаём **4 таблицы**. Техническое имя должно совпасть
буква в букву — игра обращается к ним по этим именам.

| Техническое имя | Название (RU / EN) | Что в ней |
|---|---|---|
| `weekA` | Турнир недели / Weekly tournament | турнир чётных недель |
| `weekB` | Турнир недели / Weekly tournament | турнир нечётных недель |
| `anglers` | Лучшие рыбаки / Top anglers | «слава» за всё время |
| `record` | Рыба-рекорд / Record fish | самая тяжёлая рыба, в граммах |

Для всех: тип очков — число, сортировка — по убыванию (больше — выше).

Зачем две недельные таблицы: Яндекс не обнуляет таблицы сам. Поэтому недели
чередуются (A, B, A, B…), а к очкам приклеен номер недели — старые результаты
всегда оказываются ниже новых. В самой игре номер недели не виден, игрок видит
только свои очки. Если в консоли Яндекса число выглядит огромным (например,
146 000 230) — это нормально, последние 6 цифр и есть очки.

## 4. Покупки

Раздел «Покупки» (сначала Яндекс попросит заполнить данные для выплат).
Создаём товары с такими id — они тоже должны совпасть:

| id | Название | Цена (ян) | Что даёт |
|---|---|---|---|
| `pearls_s` | Горсть жемчуга | 29 | 60 жемчуга |
| `pearls_m` | Мешочек жемчуга | 79 | 180 жемчуга |
| `pearls_l` | Сундук жемчуга | 199 | 500 жемчуга |
| `starter` | Набор новичка | 49 | красная лодка + пёс + 100 жемчуга, один раз |
| `no_ads` | Без рекламы | 99 | убирает рекламу между уловами |
| `season_pass` | Золотой пропуск | 149 | золотые награды текущего сезона |

Цены можно поменять в консоли — игра берёт их оттуда и показывает со значком
валюты Яндекса. Покупки дают только красоту и удобство, очков в турнире за
деньги не получить.

## 5. Реклама

Игра показывает:
- **видео за награду** — только когда игрок сам нажал кнопку («×2 монеты»,
  «вернуть рыбу», «подарок ×2», «заменить задание»);
- **межстраничную** — не раньше чем через 3 минуты после запуска, не чаще раза
  в 3 минуты и только в паузах (после карточки улова, при переезде на другое место).

У тех, кто купил «Без рекламы», межстраничной рекламы нет совсем.

## 6. Что проверить в черновике

1. Игра открывается, кнопка «Играть» работает.
2. Войти в аккаунт → поймать рыбу в месте недели → открыть «Топ»: своё имя
   должно появиться в таблице.
3. Купить что-нибудь в тестовом режиме → жемчуг пришёл, у имени в топе
   появилось сердечко.
4. Закрыть и открыть игру → улов и монеты на месте (облачное сохранение).

## Когда выпускать обновление

Раз в ~3 месяца — новый сезон: в `js/data/gear.js` меняем `FB.SEASON` (новый id
и награды), в `js/data/fish.js` можно добавить новое место и рыб. У нового места
ставим `tourneyFrom` — номер будущей недели, с которой оно попадёт в турниры
(подробности в комментариях в `js/game/week.js`). Не забываем поднять
`FB.VERSION` в `js/game/state.js`.
