# Рыбацкая бухта 🎣

Делаю уютную рыбалку для Яндекс Игр. Сидишь на мостках, забрасываешь удочку,
ждёшь поклёвку, вываживаешь рыбу и собираешь альбом из 44 видов. Каждую неделю
идёт турнир: у всех один и тот же пруд и своя «рыба недели», и в топ попадает
тот, у кого 10 лучших уловов окажутся круче.

Хочется, чтобы игра понравилась и детям, и взрослым, и грузилась за пару секунд
даже на слабом телефоне. Поэтому никаких движков: обычный JavaScript, а всю
графику — рыб, рыбака, пруды, погоду — я рисую кодом на Canvas. Архив для
Яндекса весит около 150 КБ.

- Как устроена игра — [docs/DESIGN.md](docs/DESIGN.md)
- Как выложить на Яндекс — [docs/YANDEX_SETUP.md](docs/YANDEX_SETUP.md)

## Как запустить у себя

Нужен только Node.js.

```
node tools/serve.js
```

и открыть в браузере http://127.0.0.1:8940. Без Яндекса игра работает в
тестовом режиме: реклама — заглушка, покупки проходят сразу, в топе сидят
выдуманные рыбаки.

## Полезные команды

```
node tools/test.js     — проверки (данные, тексты, турнир, баланс вываживания)
node tools/build.js    — собрать dist/fisherman-bay.zip для Яндекса
node tools/shot.js tools/scenarios/look.json — снимки игры в невидимом браузере
```

## Что где лежит

```
js/data/   рыбы, пруды, удочки, наживка, одежда рыбака, товары
js/game/   правила: улов, турнир недели, задания, магазин, сохранение
js/view/   рисование: пруды и погода, рыбак, рыбы
js/ui/     окна и кнопки
js/core/   общие мелочи, Яндекс SDK, звук, тексты RU/EN
tools/     сервер, тесты, сборка, снимки, страницы с набросками
docs/      описание игры и шпаргалка по Яндексу
fonts/     шрифт Nunito (лицензия OFL)
```
