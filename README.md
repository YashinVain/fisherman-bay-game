# Рыбацкая бухта 🎣

Делаю уютную рыбалку для Яндекс Игр. Забрасываешь удочку, ждёшь поклёвку,
вываживаешь рыбу и собираешь альбом из 40+ видов. Каждую неделю идёт турнир:
у всех один и тот же пруд и своя «рыба недели», и в топ попадает тот,
у кого 10 лучших уловов окажутся круче.

Хочется, чтобы игра понравилась и детям, и взрослым, и грузилась за пару секунд
даже на слабом телефоне. Поэтому никаких движков: обычный JavaScript, а всю
графику я рисую кодом на Canvas.

Как будет устроена игра, расписано в [docs/DESIGN.md](docs/DESIGN.md).

## Что где лежит

```
js/data/   рыбы, пруды, удочки, наживка, одежда рыбака
js/game/   правила: кто клюнет, турнир недели, задания, сохранение
js/core/   всякие общие мелочи
tools/     скрипты для сборки
docs/      описание игры
fonts/     шрифт Nunito (лицензия OFL)
```
